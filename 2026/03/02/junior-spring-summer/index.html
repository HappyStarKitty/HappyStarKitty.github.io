专业课

推进系统原理

  • 学分：2.5
  • 授课教师：孟华
  • 教材：喷气推进基础与应用
  • 分数构成：课堂出席10% + 平时作业20% + 大作业10% + 考试60%

mh老师采用的是手写讲义，注重公式推导。

大作业答辩时老师不会为难，基本就是指出一些小细节的不足。

飞行器总体设计

  • 学分：3.5
  • 授课教师：邹建锋
  • 教材：/
  • 分数构成：考勤10% + 课程设计40% + 期末考试50%

春学期授课，夏学期完成大作业。随机点名提问。

飞行器飞行动力学

  • 学分：2.5
  • 授课教师：吴昌聚 谢芳芳
  • 教材：
  • 分数构成
    • 期末考试60%
    • 平时成绩40%（平时作业20%+出勤5%+大作业15%）

wcj老师讲课很有意思，会有非常丰富的案例，包括诗词、时事甚至面试题目。课上会常有雨课堂回答问题。

机械制图及CAD基础

  • 学分：1.5
  • 授课教师：伊国栋
  • 教材：图学基础教程 图学应用教程
  • 分数构成：平时作业40% + 期末考试60%

作业比较固定，依次为手工绘图零件图、手工绘制装配图、AutoCad绘制零件图、AutoCad绘制装配图、Solidworks三维造型、装配图拆画零件图。

期末考试共计四道大题，分别是尺寸标注、读装配图、绘零件图。

ygd老师多次劝退非必修的同学，但无奈在培养方案。

专业选修课

飞行器结构动力学

  • 学分：2.5
  • 授课教师：徐彦 张继发
  • 教材：《飞行器结构动力学》
  • 分数构成：

课程改革后，总体设计、结构动力、飞行动力、装配与试验大作业贯通。

实际课堂只有5人，完全翘不了。xy老师讲课语速较快，主讲理论部分。zjf老师则经常调课，主讲prepromax等软件部分。

春学期大作业即总体设计的结构动力分析报告及有限元模型。夏学期作业则是完成zjf老师给的算例。

期末考试半开卷，允许带课堂笔记。

有限元方法

  • 学分：2.5
  • 授课教师：宋吉舟
  • 教材：《有限元方法基础教程》
  • 分数构成：考勤5% + 作业15% + 大作业20% + 期末考试60%

作为疑似航院唯一双语教学。

期末考试全英文，闭卷。不允许带英文词典，不需要计算器。复习参看莫聂学长和羊驼老师的笔记。

思政军体课

习近平新时代中国特色社会主义思想概论

  • 学分：3.0
  • 授课教师：何晓跃
  • 教材：《习近平新时代中国特色社会主义思想概论》
  • 分数构成：调研报告15% + 调研展示15% + 随堂讨论30% + 期末考试40%

hxy老师讲话慢而无趣，当成自习即可。

调研报告由老师评分，展示则是小组互评与老师打分各占50%。

乒乓球（初级）

  • 学分：1.0
  • 授课教师：叶亚金
  • 教材：/
  • 分数构成：专项40% + 体测30% + 考勤10% + 打卡10% + 理论5% + 引体向上5%

球拍自带。yyj老师教学不敢恭维，基本都是同学们对打，少有亲自指导。期末考核为攻球，一分钟完成60个为满分。建议找大佬纠正姿势与喂球。

短学期

  • 学分：
  • 授课教师：杨华
  • 教材：/
  • 分数构成：考勤50% + 报告50%

历时四天。yh老师明确表示没有考勤，全给满分。报告有模板。个人总结500字。
